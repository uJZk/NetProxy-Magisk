热点站点

为连接安卓热点的设备提供 HTTPS 接口。需先启用完整配置直通，且热点 DNS 请求须经过 sing-box。

站点

默认地址 192.2.0.1；会作为附加地址加入热点接口。

未提供证书时自动生成自签证书，客户端需要信任该证书。

域名解析

地址留空时使用站点地址；仅对经过 sing-box 的 DNS 请求生效。

自定义解析优先于黑名单；例外只影响黑名单，不会绕过 raw 配置原有规则。

HTTPS 自定义接口

设置路径及固定 JSON 响应；最多 8 条。内置 /、/ping、/status、/headers、/echo。

配置备份

导出的 JSON 包含用户提供的证书私钥，请妥善保管。导入后需点击保存才会生效。
