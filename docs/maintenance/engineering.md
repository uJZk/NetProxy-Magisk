# 工程准则

## 命名

页面统一使用「sing-box 配置」「sing-box 面板」「MITM」「日志」。用户可见名称使用中文，协议和配置字段沿用原名。Go、TypeScript 使用各语言惯例。已有 CLI 命令和持久字段视为兼容接口。

## 代码

CLI 与 Web 共用后端校验与持久化。更新先验证候选配置，再原子替换。导入器按来源和版本验证，缺省段保留，空列表清空。私钥仅在明确导出时读取，日志脱敏。

## UI

移动端优先，Vant 提供常用表单，Varlet 补足交互，缺失组件再用 Naive UI。json-render 只渲染本地登记组件。相同操作使用相同控件，所有字段有可见标签。

## UX

读取失败、未配置、服务停止分别显示。面板不可用时显示原因。文件导入先展示变更再保存。清除缓存保留当前可运行的配置；后台操作显示结果，失败时保留用户输入。

## v9.0.0-beta.1 发布验证

本版从 reF1nd 的两个固定标签构建 Android arm64 核心，日志级别沿用原始配置。Go 测试、go vet、WebUI 构建、发布预检与模块 ZIP 完整性检查已通过。Android 真机上的升级、开机启动及客户端 HTTPS 连通性仍待验证。
