# 完整配置直通维护记录

基于上游 8.6.2，模块支持通过 `config raw` 下载并直接运行完整 sing-box 配置；使用方法见 [CLI 指南](../guide/cli.md#完整配置直通)。不迁移旧格式，也不为管理器新增直通界面。直通状态 `running` 表示进程存活，不证明入站就绪。

配置更新先执行核心检查，再原子替换；运行中的配置更新后重启核心，启动失败时尝试恢复上一份配置。自动更新复用现有 Worker，保留全部数据的模块升级会保留直通文件。

模块更新地址指向本仓库的最新正式 Release；Release 工作流生成 `update.json`。Telegram 通知与上游 KernelSU 仓库分发在本仓库禁用。

2026-10-31 执行 `tests/verify.sh quick` 通过，覆盖 Go 测试、Android arm64 CLI 构建、Shell 和发布契约；完整配置的真实设备网络行为仍需在 Android 真机验证。后续修改应继续验证真实配置和升级时的数据保留。

`v8.6.2` 的发布因缺少管理器签名密钥和 PostHog 配置而失败。后续模块包不附带管理器 APK，不注入 PostHog 配置，保留 Android 平台辅助程序；采用新版本标签发布，避免修改已有标签。真机验证仍未进行。
