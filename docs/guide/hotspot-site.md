# 热点 HTTPS 站点

热点站点使用安卓系统已有的热点，为连接该热点的设备提供固定 JSON HTTPS 接口及自定义域名解析。模块不会创建热点，也不采集设备流量。进入模块管理器的 NetProxy 控制中心，打开「热点站点」配置。

先启用[完整配置直通](/guide/cli#完整配置直通)，并让 raw 配置接管热点客户端的 DNS 请求。启动安卓热点后，在页面设置域名、DNS 和接口，开启站点并保存。页面可重新读取后台状态；「已监听」表示 HTTPS 端口已绑定，不代表客户端 DNS 或网络已连通。

站点在识别到的无线热点接口增加 `192.2.0.1/32`，不替换安卓原有的热点地址。这个地址位于公网地址空间，发往同一地址的连接会落到本机，可能影响访问原公网服务。如果设备不暴露可识别的无线 AP、出现多个热点接口、地址已用于其他接口或 443 端口被占用，页面会显示错误；模块不会猜测接口或覆盖现有地址。关闭站点时清理模块添加的地址。

启用站点后，模块在 raw 配置的运行时副本中，将站点域名和自定义解析、DNS 黑名单插入 `dns.rules` 前部；原始下载文件不变。自定义解析使用精确域名，IPv4 留空时指向 `192.2.0.1`；非 A 查询返回空应答。黑名单支持 `*`、`?`，例外精确匹配；自定义解析优先于黑名单。黑名单例外只跳过此处的黑名单，后续 raw 配置规则仍会生效。客户端自行使用加密 DNS 或未被 raw 配置接管时，这些规则不会生效。

站点默认域名为 `www.aabbcc.com`。可以提供 PEM 证书链与对应私钥；不提供时生成并保存自签证书，客户端必须信任该证书。更新证书或规则会重启站点；如果 sing-box 正在运行，保存也会重启核心以应用 DNS。内置 `/`、`/ping`、`/status`、`/headers`、`/echo`，另可添加最多 8 个路径到固定 JSON 的接口。路径匹配不区分大小写，按完整路径段匹配，多个命中时使用最长路径。

页面可导出或导入 JSON 备份。备份包含用户提供的私钥，请妥善保存；自动生成的自签证书由设备保存，不包含在备份中。导入后要点击「保存设置」。此备份格式与 ESP32 项目的 YAML 备份不同。

如无法访问，先查看页面后台状态及服务日志，再检查安卓热点、防火墙、443 端口、客户端到 `192.2.0.1` 的路由和 DNS 是否经过 sing-box。当前实现需要在具体安卓系统和内核上验证热点接口识别、地址添加与客户端连通性。
